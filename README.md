# Fusion AI


Fusion AI is a lightweight, on-device AI system designed to improve the user experience. It does not connect to external servers, does not collect user data, and performs only the tasks it is designed to do. Most of Fusion AI runs silently in the background of the app and does not include a traditional chat interface.


This repository is provided for educational and reference purposes. You are welcome to study the code and use it as inspiration for your own projects. However, this code should not be copied and pasted into another application or redistributed under a different name.


If you use a significant portion of Fusion AI as a reference while developing your own on-device AI system, please provide appropriate credit to the Fusion AI project.
